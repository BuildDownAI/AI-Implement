## Scope and gates

The feature branch has 60 merged child PRs and no open child PRs at this checkpoint. The [AII-813 fault matrix](https://github.com/BuildDownAI/AI-Implement/pull/715) landed as `d46a6fb`; the [AII-812 cleanup audit](https://github.com/BuildDownAI/AI-Implement/pull/720) landed as `03b0eed`; the [AII-814 decisions and runbook](https://github.com/BuildDownAI/AI-Implement/pull/718) landed as `a123a56`. AII-812 found no exclusive in-process Restate lifecycle branch left to delete. Its inventory identifies the durable delivery nudge, callback ingress, shared history, and guards that keep Legacy monitors away from Restate-owned attempts. The unsuccessful draft [PR #719](https://github.com/BuildDownAI/AI-Implement/pull/719) was closed without merging: it added failing tests but removed no production glue.

The project setting remains `null` in existing mapping rows unless selected, and `resolveReviewFixLifecycle` returns `legacy` for `null` (`src/config.ts`). The switch routes only automatic GitHub Actions review-fix to Restate; local review-fix and human comment work stay on Legacy admission (`src/index.ts`, `src/__tests__/review-fix-drain.test.ts`). The runner still performs its own internal review/fix cycles; the Restate `ReviewFixAttempt` workflow coordinates the outer attempt. These are source inspection results, not a deployed-setting observation.
